# ☕ Starbucks Beverage Analytics Dashboard

## 📌 Project Overview
This project presents an interactive Starbucks Beverage Analytics Dashboard developed using Microsoft Power BI. It explores different Starbucks beverage categories, preparation methods, and nutritional information to provide a clear visual understanding of the beverage menu.

## 🎯 Project Objectives
- Analyse different Starbucks beverage categories.
- Explore beverage preparation methods.
- Compare nutritional values across beverages.
- Understand caffeine, calories, sugar, protein, and dietary fibre content.
- Present data through interactive visualizations.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## 📊 Dashboard Features
- Beverage Category Analysis
- Beverage Preparation Analysis
- Calories Analysis
- Average Caffeine Analysis
- Sugar Content Analysis
- Protein Analysis
- Dietary Fibre Analysis
- Interactive charts and filters
